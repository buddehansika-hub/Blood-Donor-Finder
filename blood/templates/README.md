# Blood Donor Finder

## Overview

Blood Donor Finder is a Django web application that helps users search for blood donors based on blood group and city.

## Features

- User Registration
- Login & Logout
- Donor Profile
- Search Donors
- Blood Request
- Accept / Reject Requests
- Admin Dashboard

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap 5

## Installation

```bash
git clone <repository-url>
cd BloodDonorFinder
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Visit:

```
http://127.0.0.1:8000/
```
